## 🎯 Objetivo do Projeto
O projeto tem como objetivo exercitar os conhecimentos da sala de aula criando um site em HTML5, organizando adequadamente as estruturas de títulos, imagens, seções de informações, parágrafos e links.

## 🛠️ Tecnologias Utilizadas
* **HTML5**

## 📌 Descrição da Página
A página desenvolvida apresenta informações sobre o filme *Esqueceram de Mim*, trabalhando com a aplicação prática das tags fundamentais do HTML5:
* **Títulos (`<h2>`)**: Para a estruturação de seções da página.
* **Parágrafos (`<p>`)**: Para apresentação dos textos e sinopse.
* **Imagens (`<img>`)**: Para exibição de elementos visuais do filme.
* **Links (`<a href="...">`)**: Para navegação e links externos.
